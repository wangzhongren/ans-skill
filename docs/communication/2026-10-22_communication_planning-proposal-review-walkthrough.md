## 2. 走查链

1. **W1**：策划作者写 D1 走查样本初稿，声明按 A3 第 3.2 节使用轻量复核，并核对五项条件均满足。
2. **D2 首次复核**：独立策划复核上下文按 L1–L6 复核 W1，记录发现 F1（一般，实质修订自标缺少再复核触发点）、F2（建议，修订说明载体和位置未写明），结论“建议提交客户确认”。
3. **W2 处置**：作者逐项处置 F1、F2，均采纳；在 D1 的“复核处置”节写明理由和改动位置，形成 W2。
4. **W3 实质修订**：作者在 W2 基础上增加 2.3“版本身份证据与失败分支”（哈希优先、章节清单+交接时间次之、都没有则按复核缺口），收紧 S1、S4，新增 S5，并标注为实质修订。
5. **D2 再复核**：独立复核上下文只复核受影响部分，确认 F1、F2 已关闭，新增 F3、F4 建议级发现，结论“建议提交客户确认”；未重做未变化部分。
6. **D3**：沟通整理本材料包，明确“走查材料，不是客户确认”。

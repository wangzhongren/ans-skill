# 四类工作与五条转换方案复核记录

- 复核模式：**完整**。选择依据：本方案跨沟通、策划、统筹、人事、验收、技能规范多个角色，涉及流程/治理/边界与闸门适用性，含 O1–O15 多个选装和多个待客户决定事项，修复快速通道改变闸门 1/2 的适用解释；按[复核规则第 3.3 节](../../../../references/planning-proposal-review.md)不能按轻量复核，须逐项检查 OD-1 至 OD-5、MK-1 至 MK-6。

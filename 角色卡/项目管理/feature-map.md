# 项目管理功能导航

本角色承接独立策划形成的产品／需求方案，负责技术架构、实现设计、技术评审、跨角色契约、项目工程法案和获准的共享代码及其测试。后续需求在客户实施授权后由统筹安排；策划不取代本角色技术评审。当前没有直接提供给技能使用者的独立产品功能；全项目派发与进度由统筹调度负责，最终成果判断由独立验收负责。所有项目角色平级，group 仅分类。

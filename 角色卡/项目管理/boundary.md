# 项目管理边界

## Section 1: 可修改文件与目录

| 类型 | 可操作路径 | 用途 |
| --- | --- | --- |
| 单文件 | `doc/design/2026-10-10_design_project-plan-role-memo.md` | 本项目法案与 memo 方案设计稿 |
| 单文件 | `角色卡/项目管理/docs/design/2026-10-10_design_project-rules-memo-review.md` | 本轮项目法案与 memo 方案的治理评审记录 |
| 单文件 | `角色卡/项目管理/docs/project-rules.md` | 全项目唯一工程法案 |
| 单文件 | `角色卡/项目管理/docs/architecture.md` | 项目整体架构及角色协作说明 |
| 单文件 | `角色卡/项目管理/memo.md` | 项目管理角色的工作备忘录 |
| 单文件 | `角色卡/项目管理/feature-map.md` | 本角色的功能导航；可说明无直接业务功能 |

未列路径默认只读。此边界不授权修改本角色卡、边界、变更记录、技能文件、其他角色资料、业务代码或测试。新增日期文档、目录或其他文件须先由 ANS Governance 更新并由用户确认边界。

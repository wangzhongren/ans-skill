# 统筹调度边界

## Section 1: 可修改文件与目录

| 类型 | 可操作路径 | 用途 |
| --- | --- | --- |
| 单文件 | `角色卡/统筹调度/feature-map.md` | 本角色功能导航；说明无直接负责的业务功能 |
| 单文件 | `角色卡/统筹调度/memo.md` | 本角色私有工作备忘录 |
| 单文件 | `角色卡/统筹调度/docs/coordination/2026-10-19_role-authority-split-handoff.md` | 本轮职责迁移和协作交接文档 |
| 单文件 | `角色卡/统筹调度/docs/coordination/2026-10-20_workflow-fixes-handoff.md` | 工作流缺口修复协调交接 |
| 条件目录 | `docs/scheduling/` | 团队计划、角色调整方案与调度记录；不含业务代码、其他角色文档或治理文件 |

未列路径默认只读。本角色按统筹职责在自己获准的 `docs/scheduling/` 范围写团队计划和角色调整方案；此边界不授予任务记录、业务代码、其他角色文档、测试文件或治理文件的写入权限。不得自行创建任务 ID、手工写入全局调度状态或代表验收提交结论；未来任务记录路径须由 ANS 人事按已授权工具与具体任务精确增加。

本轮 2026-10-20 治理授权仅增加表中列出的本角色工作文档路径；不扩大其他角色或程序文件权限。

本轮 2026-10-22 按五内置管理角色模型增加 `docs/scheduling/` 条件目录，用于统筹写团队计划和角色调整方案后交招募（现人事）执行；其他路径与权限不变。

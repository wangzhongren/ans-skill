# 工单草稿为什么要先保存再退出

> 教学示例；以下工单页面和保存接口并不存在于本仓库。

客服处理工单时，可能填了一半就要去回复另一位买家。如果页面先关、草稿却没存上，刚输入的内容就丢了。所以按这个顺序做：**先存上，再关页面**。

```text
点“保存退出” → 收集当前字段和处理备注 → 保存草稿
                                         ├─ 成功：提示已保存，返回列表
                                         └─ 失败：留在详情页，保留输入并提示原因
```

这里只设计草稿保存和退出，不改审核提交。草稿表示“下次继续编辑”，不表示“工单审核通过”。草稿按工单 ID 保存；再次打开时，把原来填的内容放回表单。

以后要检查三件事：存上了才退出；没存上时输入还在；重新打开能接着编辑。现在还没做，也没测。

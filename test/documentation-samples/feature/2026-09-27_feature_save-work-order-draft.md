# 客服怎样保存未完成的工单

> 教学示例；这是“新增功能文档”的写法，不表示本仓库已经提供工单页面。

客服暂时不能完成工单时，可以把已填写的字段和处理备注保存为草稿，稍后回来继续，而不用重新输入。

例如，客服已经写好问题说明，但还在等买家的物流单号：

1. 在工单详情里填写已有信息，点击**保存退出**。
2. 看到“草稿已保存”后，页面返回工单列表。
3. 下次打开这张工单，先前填写的内容仍在，可以继续编辑或再提交审核。

如果没存上，页面不退出，已输入的内容还在，客服可以重试。这里只新增保存草稿，不改提交审核。工单仍是“待处理”。

这只是写法示例。功能还没做，也没测。

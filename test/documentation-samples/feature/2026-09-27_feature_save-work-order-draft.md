# 客服怎样保存未完成的工单

> 教学示例；这是“新增功能文档”的写法，不表示本仓库已经提供工单页面。

客服暂时不能完成工单时，可以把已填写的字段和处理备注保存为草稿，稍后回来继续，而不用重新输入。

例如，客服已经写好问题说明，但还在等买家的物流单号。按这个顺序走完整条“保存草稿”流程：

1. 打开一张还没提交审核的工单，填写已有字段和处理备注。
2. 点击**保存退出**。页面把工单 ID、当前字段和处理备注交给“保存草稿”接口。接口检查这张工单能否保存，再把草稿写入存储；这一步不提交审核。
3. **存上了**：提示“草稿已保存”，返回工单列表。工单仍是“待处理”。
4. **没存上**：留在详情页，原输入不清空，提示失败原因。客服可以改好内容后再点一次。
5. 之后重新打开这张工单，先前存好的字段和备注会填回来，客服可以继续编辑，再决定是否提交审核。

这里只新增保存草稿，不改提交审核。直接关掉页面却没有点“保存退出”时会怎样，本示例还没定义，不要把它写成已支持的流程。

这只是写法示例。功能还没做，也没测。

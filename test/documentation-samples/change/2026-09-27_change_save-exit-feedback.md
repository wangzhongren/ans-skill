# 保存退出现在会告诉客服有没有存上

> 教学示例；下面的“以前”和“现在”是假设的产品变化，不对应本仓库代码。

客服点“保存退出”，以前页面一下就关了。内容没存上，客服也可能不知道。现在保存成功才回列表；没存上就留在原页：

| 发生的情况 | 以前 | 修改后 |
| --- | --- | --- |
| 保存成功 | 直接回到列表，结果不明确 | 提示“草稿已保存”，再回列表 |
| 保存失败 | 页面也可能关闭 | 留在详情页，保留输入并提示原因 |

这次只改提示和关页时机。保存草稿的方式不改。提交审核的流程也不改。已经存好的草稿不用迁移。客服仍点同一个按钮；失败时留在原处重试。

这只是写法示例。代码还没改，也没测。
